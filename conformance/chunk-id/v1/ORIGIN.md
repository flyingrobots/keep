# Chunk Identity Corpus Origin

All fixture definitions in this directory were authored for Keep.

The hash grammar is governed by
`docs/invariants/chunk-identity/README.md`. Expected digests were generated
from the documented byte grammar with `b3sum` 1.8.5 and are independently
recomputed by `check_vectors.py`.

The fixture contains no third-party corpus bytes, private workspace material,
credentials, paths, or application data.
