# Architecture Decision Records

Keep records decisions that affect identity, durable formats, durability,
recovery, concurrency, garbage collection, encryption, or public compatibility
as numbered architecture decision records (ADRs).

An ADR is a protocol commitment, not proof that its implementation has shipped.
Executable evidence and the changelog establish implementation maturity.
