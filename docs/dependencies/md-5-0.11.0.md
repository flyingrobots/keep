# Dependency Admission: md-5 0.11.0

**Status:** Admitted for repository-owned conformance tooling.  
**Owner:** CDC profile v1 conformance.  
**Scope:** The `xtask` package with the `repository-tasks` feature.

## Admitted use

`md-5` regenerates the public Gear-table recipe documented by
[`conformance/cdc-profile/v1/README.md`](../../conformance/cdc-profile/v1/README.md).
For each byte value, the checker hashes 64 repetitions of that byte and retains
the first eight digest bytes. The resulting 2,048 bytes must equal the
authoritative `gear-table.bin`.

MD5 is not a Keep identity, checksum, signature, password primitive, or security
boundary. Runtime code consumes the frozen Gear-table bytes and does not depend
on this crate.

## Why this dependency is needed

Issue #57 moves the independent CDC checker from Python into Rust. The checker
must reproduce the language-neutral MD5 recipe without retaining Python or
depending on an ambient `md5` executable. A reviewed RustCrypto implementation
is smaller and easier to audit than a repository-owned digest implementation.

## Build and feature posture

- Version `0.11.0` is pinned exactly in `xtask/Cargo.toml`.
- Default features are disabled.
- The dependency is optional and admitted only by `repository-tasks`.
- Its declared Rust version is 1.85, below Keep's pinned Rust 1.96 toolchain.
- It adds `digest`, `block-buffer`, `crypto-common`, `hybrid-array`, and
  `typenum` to the locked `xtask` graph.
- It is implemented in Rust and does not introduce a scripting runtime.

The upstream package is dual licensed under MIT or Apache-2.0. Its source and
release metadata are maintained by the
[RustCrypto hashes project](https://github.com/RustCrypto/hashes).

## Public API and compatibility

No dependency-owned type crosses an `xtask` module boundary or enters Keep's
library API. Removing or replacing the crate does not change stored bytes,
public Rust APIs, or the CDC profile. Any replacement must regenerate the exact
first and last Gear entries and the complete authoritative table.

## Rejected alternatives

### Retain the Python checker

Rejected because Keep is a pure Rust project and repository policy forbids
Python scripts.

### Invoke an ambient MD5 executable

Rejected because it would add another host tool, version boundary, process
failure mode, and platform dependency to the conformance gate.

### Implement MD5 inside `xtask`

Rejected because a local digest implementation would add security-sensitive
bit-level code whose only purpose is reproducing a public fixture recipe.

## Review triggers

Re-review this admission when:

- the CDC Gear-table recipe or profile version changes;
- `md-5` changes its feature graph, license, Rust version, or implementation
  posture;
- the dependency becomes reachable from production library code;
- a smaller reviewed Rust boundary can preserve the same independent witness;
  or
- dependency policy reports an advisory or license conflict.
